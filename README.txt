POWERED BY GURU — FUTURE INTERFACE
===================================

Files:
- index.html  Main webpage structure
- style.css   Responsive green/black design and animations
- script.js   Mobile menu, scroll reveal, cursor glow, demo form response

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is only needed for the optional Google Fonts; the page itself uses plain HTML, CSS, and JavaScript.

Notes:
- No React, framework, or animation library is used.
- Contact form is a front-end demo and does not send messages to a server.
- You can edit the text in index.html and colors near the top of style.css.
